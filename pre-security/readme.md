# Core Foundations – TryHackMe Pre Security

This folder contains notes and writeups from the foundational section (01–11) of the TryHackMe Pre Security path.

It focuses on core computing and cybersecurity fundamentals required before moving into practical penetration testing topics.

## Topics covered

- How websites work (client-server model, HTTP basics)
- Computer systems and architecture
- Types of computers and use cases
- Virtualisation and cloud computing basics
- Operating systems fundamentals
- Data representation (binary, ASCII, etc.)
- Data encoding principles
- CIA triad (Confidentiality, Integrity, Availability)
- Cryptography basics

## Purpose

The goal of this section is to build a solid theoretical base for:
- networking and infrastructure understanding
- SOC analysis fundamentals
- penetration testing preparation

## Notes

Each file contains structured explanations and personal notes aimed at reinforcing core concepts and preparing for hands-on security labs in later sections.
